# Provider documentation

Downloaded from the official [StatsBomb Open Data repository](https://github.com/statsbomb/open-data/tree/4b73468fc5b0f1950f9f66fada70ad3a4f9327cb/doc) on 22 October 2026, before implementation. PDFs and extracted text are retained for review:

- `Open Data Events v4.0.0.pdf`: event fields and corner-pass/shot types.
- `StatsBomb Open Data Specification v1.1.pdf`: event clocks, possession, pass techniques and coordinate appendix.
- `Open Data 360 Frames v1.0.0 (1).pdf`: event UUID join, visibility polygon, frame-player fields, orientation and missingness caveats.
- Competition, matches and lineup specifications describe the metadata structures. Lineups are not needed by this MVP.
- `LICENSE.pdf`: StatsBomb Public Data User Agreement, last updated 8 September 2023. These source materials retain provider rights and are excluded from the authored-code licence.

The [official attribution logo](../../assets/SB%20-%20Icon%20Lockup%20-%20Colour%20positive.png) comes from `img/SB - Icon Lockup - Colour positive.png` at the pinned revision, without modification. Public findings use it as required by the agreement and repository README.
