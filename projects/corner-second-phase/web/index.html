What this can say

The data describe historical Euros, not the effect of the Premier League's 2026/27 refereeing guidance. A clearance event is not proof that a team won possession. A goalkeeper action, block, or duel can occur at the same recorded instant as a shot, so phase labels can be uncertain.

Rates use one corner as the unit. Intervals resample whole matches. StatsBomb's public data is supplied for research under its public-data agreement; the provider's raw event feed is not reproduced here.
