# Pass Decision Lab visual direction

User selected: warm-paper editorial, with antislop applied during the build.
Audience: football analysts exploring historical pass choices and testing model evidence.
Energy 2 / Rhythm 2 / Motion 1.

- Warm paper and dark ink support sustained reading of dense evidence.
- Teal identifies visible teammates and hypothetical ground-pass lanes; rust identifies opponents and the recorded actual pass. Dashed/solid geometry and labels duplicate color distinctions.
- A large pitch is the focal point. Possession selection precedes pass selection; model evidence follows the individual decision.
- Native Streamlit sans-serif controls preserve keyboard interaction. Serif chart titles provide the editorial accent without remote fonts.
- Whitespace separates the pitch, candidate estimates and validation. Tables remain scrollable and controls stack on narrow screens.
- Fixed light figures match the paper theme, keeping pitch and annotation contrast stable. No decorative animation, logos invented by this project, hero cards or external fonts.
- The StatsBomb logo is an existing official attribution asset already stored in this repository; use it without modification.

## Public companion

The static companion carries the same user-selected paper/ink direction and 2/2/1 dials. A narrow selection column and large pitch keep the decision visible; model evidence and methods have separate views because they answer different questions. Native selects provide keyboard behavior, contained tables preserve exact comparisons, and all case images retain the same spatial encodings. Typography uses local system sans-serif and Georgia, with no font requests. Hash links identify a published case. No promotional cards, animation or invented tactical narrative is introduced.
