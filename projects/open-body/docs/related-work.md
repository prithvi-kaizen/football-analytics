# Related methods and the contribution here

1. **SkillCorner / PySport, Body Pose tutorial and `src/features/pose_orientation.py` (public implementation).** [Tutorial](https://github.com/SkillCorner/opendata/blob/4340d274572876239c154c90bc507a9b3250a656/notebooks/tutorials/05_Body_Pose/Part1_Getting_Started_with_Body_Pose.ipynb). Shows loading, error/width gating, a shoulder heading from the left-to-right shoulder axis rotated +90°, and 25/10 Hz alignment. It explicitly warns to smooth before differentiating. This project reuses that geometric convention, independently implements causal reception-window features, validates full-match joins, measures selection and compares outcomes and held-out models. The shoulder-vector formula itself is not novel.

2. **Arbués-Sangüesa et al., “Always Look on the Bright Side of the Field: Merging Pose and Contextual Data to Estimate Orientation of Soccer Players,” ICIP 2020.** [Paper](https://arxiv.org/abs/2003.00943). Estimates torso orientation from projected pose and ball context, evaluates against wearable orientation, and introduces orientation maps. It establishes that body orientation can be estimated and visualised, with measurement error. This pilot consumes supplied 3D estimates and does not train or validate a new pose detector. It also avoids ball-based correction of heading, which could build the desired orientation relation into the feature.

3. **Arbués-Sangüesa et al., “Using Player's Body-Orientation to Model Pass Feasibility in Soccer,” CVPR Workshops 2020.** [Paper](https://openaccess.thecvf.com/content_CVPRW_2020/papers/w53/Arbues-Sanguesa_Using_Players_Body-Orientation_to_Model_Pass_Feasibility_in_Soccer_CVPRW_2020_paper.pdf). Combines orientation, defender configuration and distance to model feasible receivers and studies combining orientation with EPV. Thus “orientation matters for passes” is not a new research claim. Our narrower contribution is an open-data, reception-centred, match-separated ablation with matched samples, causal feature timing and missing-pose accounting, focused on fast forward release rather than receiver selection.

4. **Jordet et al., “Scanning, Contextual Factors, and Association With Performance in English Premier League Footballers: An Investigation Across a Season,” Frontiers in Psychology, 2020.** [Paper](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2020.553813/full). Separately codes scanning, match context, body orientation and performance; uses contextual modelling of pass completion. This supports context adjustment and the distinction between body orientation and scanning. The present shoulders-only measurements cannot reproduce its head-scanning construct or establish cognitive mechanisms.

5. **Laurie Shaw / Friends of Tracking, `LaurieOnTracking` (public implementation).** [Repository](https://github.com/Friends-of-Tracking-Data-FoTD/LaurieOnTracking). Provides reusable tracking processing, velocity estimation, pitch-control and EPV examples using Metrica data. It motivates interpretable tracking context and unit-aware feature engineering. This project uses SkillCorner only and a deliberately simpler pressure baseline; it does not claim to implement full pitch control or a new EPV model.

No reported effect size from these papers is treated as a result of this project. No independent orientation ground truth is available here. The implementation contribution is a reproducible measurement and evaluation pipeline with an inspectable tactical animation, not a discovery that receiving orientation universally causes better play.
