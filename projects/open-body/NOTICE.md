# Data and source attribution

This project uses SkillCorner Open Data, released jointly with PySport, including the SkillCorner body-pose testing release. Credit: [SkillCorner](https://skillcorner.com) and [PySport](https://pysport.org).

The upstream repository and Hugging Face dataset declare MIT. The original SkillCorner copyright and licence notice are preserved in `docs/source/data_LICENSE.txt`. Retain that notice with redistributed data and substantial derived portions. `LICENSE` covers this project's code; it does not replace SkillCorner's data notice.

The shoulder heading convention matches SkillCorner's official public tutorial, with an independent implementation here. The original tutorial and geometry source are preserved for inspection under their upstream licence. Research citations are in `docs/related-work.md`; papers are references, not redistributed datasets or training inputs.

No broadcast video footage, paid data or paid API is used. The animated demo is rendered from the released coordinates and skeletons.
